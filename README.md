# Lightbringer

3인칭 판타지 액션 디펜스 게임 Lightbringer의 배포 파일 저장소입니다.

홈페이지: https://lightbringer.jeondowon.com

## 다운로드

[Releases](https://github.com/jeondowon/lightbringer_release/releases/latest)에서 내려받습니다.

| 파일 | 대상 |
|---|---|
| `Lightbringer-1.0.0-Windows.zip` | Windows 10 이상 (64비트) |
| `Lightbringer-1.0.0-macOS.zip` | macOS 12 이상 (Apple Silicon · Intel) |

## 설치

**Windows**

1. zip 파일의 압축을 풉니다.
2. 폴더 안의 `Lightbringer.exe`를 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.

**macOS**

1. zip 파일을 열면 `Lightbringer.app`이 나옵니다.
2. `Lightbringer.app`을 Finder의 "응용 프로그램" 폴더로 옮긴 뒤 실행합니다.

새 버전으로 바꿀 때 진행 상황은 그대로 남습니다.
